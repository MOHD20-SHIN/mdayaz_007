# AI & Machine Learning - Basics

A beginner-friendly Python practice repository covering introductory AI, Machine Learning, Deep Learning, and core Python programming concepts.

## Topics covered

- Introduction to Artificial Intelligence, Machine Learning, and Deep Learning
- Variables and data types
- Input and output
- Conditional statements (if-else)
- For and while loops
- Lists
- Functions
- Beginner programs:
  - Add two numbers
  - Even or odd checker
  - Multiplication table
  - Count vowels
  - Factorial
  - Simple calculator

## Requirements

- Python 3.8 or later
- No external packages are required

## How to run

1. Clone or download this repository.
2. Open a terminal in the repository folder.
3. Run:

```bash
python ai_ml_basics.py
```

4. Select an exercise from the menu.

## Purpose

This project is for learning and practising Python fundamentals as a foundation for AI and Machine Learning.

Happy coding!
